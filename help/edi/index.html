Overview

TFS EDI exchanges X12 documents with your trading partners inside Business Central: 850 purchase orders in; 855 acknowledgments, 856 ship notices and 810 invoices out. Partner differences live in rules on the partner, and anything that doesn't fit goes to the EDI Exceptions worklist.

Built-in transmission (AS2, SFTP, VAN) isn't available yet. Outbound documents wait as Ready to Send, and Download & Mark Sent stands in until it is.

Transaction statuses

StatusMeaning
NewImported, not processed yet
ProcessedAn inbound document became a Business Central document
ExceptionSomething needs a person. See the error code.
Test OKA test file (ISA15 = T) was checked successfully without creating an order
Ready to SendAn outbound document is ready to go
HeldAn outbound document is waiting on something, such as an 810 waiting for its 856s or an 856 waiting for cartons
SentThe outbound document was sent
ExportedThe file was exported
CancelledCancelled from the worklist

Error codes

Every exception has one of these codes. From the EDI Exceptions page you can Fix (opens the setting that needs changing), Reprocess, Process Anyway (for duplicates and replacements) or Cancel.

CodeWhat happened
PARSE_FAILEDThe file couldn't be read as X12.
UNSUPPORTED_DOCUMENTThe file is a transaction set the app doesn't handle yet.
PARTNER_NOT_FOUNDNo partner matches the sender's qualifier and ID.
PARTNER_DRAFTThe partner is still in Draft, so its files aren't processed.
PARTNER_TESTINGA production file arrived for a partner that is still in Testing.
PARTNER_BLOCKEDThe partner is blocked.
NO_CUSTOMERThe partner isn't linked to a customer.
SHIPTO_NOT_MAPPEDThe ship-to location on the order doesn't match a ship-to address.
ITEM_NOT_FOUNDNo item matches the product IDs on the line.
UOM_NOT_FOUNDThe unit on the line doesn't match a unit of measure for the item.
UOM_NOT_DIVISIBLEThe quantity doesn't divide into the item's sales unit. The message names both nearest pack counts.
MISSING_PRODUCT_IDAn outbound document needs a product ID the item doesn't have.
DUPLICATE_POThe PO was already invoiced inside the duplicate window.
DUPLICATE_RESENDThe 850 is marked as a duplicate by the partner.
REPLACE_POThe 850 replaces an earlier PO and needs a decision.
WAITING_FOR_CARTONSThe partner needs carton detail on the 856 and none has arrived for the shipment yet.
BC_ERRORBusiness Central raised an error while creating the order. The message has the details.
