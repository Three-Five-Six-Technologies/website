Ten signals, each with a next step

Each signal gets a count, a status (OK, Warning or Critical) and a recommendation, for the last 24 hours, 7 days or 30 days. Thresholds scale with the time range.

SignalAreaWhat it tells you to do
Error messages shown to usersErrorsReview the most frequent error messages; repeated errors often point to missing setup or training needs.
Permission errorsErrorsUsers are blocked by missing permissions. Review their permission sets.
Database deadlocksPerformanceTwo processes blocked each other. Check job queue schedules and integrations that run at the same time.
Database lock timeoutsPerformanceUsers or jobs waited too long for locked data. Spread out heavy postings and job queue entries.
Slow database queriesPerformanceSome queries take longer than 750 ms. Check filters, keys and extensions on busy pages.
Slow AL operationsPerformanceSome AL code takes longer than 10 seconds. Identify the extension and object involved.
Job queue failuresAutomationOpen Job Queue Entries and check the error for failed entries, then restart them.
Failed incoming web service callsIntegrationsAn integration calling Business Central is failing. Check its credentials and the endpoints it uses.
Failed outgoing web service callsIntegrationsBusiness Central calls to another system are failing. Check that service and its credentials.
Active usersUsageNumber of distinct users who opened pages. Compare with your license count.

No Power BI, no KQL

The queries are built in. Open the dashboard, pick a time range, read the recommendations.

A connection test that explains itself

Test Connection tells you if you're connected with data, connected with no data in the last 24 hours, or not connected, and why.

Your data stays in Azure

It reads your telemetry on demand and doesn't copy it into Business Central. The client secret is kept in isolated storage, not in a table.

Just this environment, or all of them

By default it only counts telemetry from the environment you're in. Turn that off to see everything the resource receives.

About 15 minutes to set up

You need admin access to the Azure portal and to Business Central. You'll send BC telemetry to an Application Insights resource (skip this if you already do), create an app registration with the Reader role, then paste four values into Telemetry Monitor Setup.
